# 🎬 Movie Recommender System

A **content-based movie recommendation system** built using **Python**, **Machine Learning**, and **Streamlit**.  
It recommends movies similar to the one selected by the user and displays their posters using the **TMDB API**.

---

## 🚀 Live Demo
👉 https://movierecommendersystem-mhnsae4aepffwmqdlhrik9.streamlit.app/ 


---

## 🧠 How It Works
- Uses **cosine similarity** on movie metadata
- Finds the most similar movies
- Fetches movie posters using **TMDB API**
- Displays recommendations in an interactive UI

---

## 🛠 Tech Stack
- **Python**
- **Pandas, NumPy**
- **Scikit-learn**
- **Streamlit**
- **TMDB API**
- **Pickle (for model persistence)**
